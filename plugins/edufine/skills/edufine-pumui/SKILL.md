# 에듀파인 품의 만들기

견적서를 읽어 에듀파인 [품의목록 > 신규] 화면에 그대로 옮길 내용을 만든다.
금액 계산과 한글 금액(금일백칠십사만구천원정)은 직접 쓰지 말고 반드시 `scripts/pumui.py`로 만든다.

## 순서

1. **견적서 읽기.** 품명, 규격, 수량, 단가, 금액, 견적 합계, 공급자 상호를 표로 옮긴다.
   - 각 행에서 `수량 × 단가 = 금액`인지, 행 금액의 합이 견적 합계인지 확인한다. 안 맞거나 글자가 흐리면 사용자에게 묻는다.
   - 구입처는 공급자 상호를 쓴다(예: `○○사무기기`).
2. **빠진 정보 묻기.** 견적서에 없는 것은 한 번에 모아 묻는다.
   - 위치(예: `2학년,4학년 연구실`), 건명(제목). 건명은 `<위치> <물품> 구입` 꼴로 제안하고 확인받는다.
   - 붙임이 기본(`지출품의서 1부`, `견적서 1부`)과 다르면 받는다.
3. **입력 JSON 쓰기.** 작업 폴더에 `pumui-input.json`으로 저장한다.
   ```json
   {
     "subject": "2학년,4학년 연구실 복사기 토너 구입",
     "location": "2학년,4학년 연구실",
     "vendor": "○○사무기기",
     "items": [
       {"name": "K토너", "spec": "CM2075", "qty": 4, "unit": "개", "price": 121000}
     ],
     "attachments": ["지출품의서 1부", "견적서 1부"],
     "quoteTotal": 1749000
   }
   ```
   - `name`은 에듀파인 품목 `내용` 칸에 들어갈 이름이다. 견적서 품명을 그대로 쓰되 사용자가 줄여 쓰는 습관(예: `K토너`)이 있으면 따른다.
   - 개요 `내역`의 색상 표기는 자동이다: 품명 끝 K/C/M/Y → 검정/파랑/빨강/노랑. 다르게 쓰려면 항목에 `"label"`을 넣는다.
   - `quoteTotal`은 견적서 합계(세액 포함)이다. 스크립트가 검산한다.
4. **실행.** `python3 <이 스킬 폴더>/scripts/pumui.py pumui-input.json`
   - `견적서 합계 검산: 불일치`가 나오면 멈추고 사용자에게 어느 행이 다른지 알린다.
5. **보여 주기.** 아래 순서로, 복사하기 쉽게 각각 코드 블록에 담는다.
   - 제목
   - 개요 (스크립트 출력 그대로, 앞 공백과 `.  끝.`의 두 칸 띄움 유지)
   - 품목내역 표 (순번·내용·규격·수량·단위·예상단가·예상금액, 끝에 요구금액)
   - `[자동입력 데이터]` 한 줄과, 그 데이터를 쓰는 법: 에듀파인에서 [신규] → 즐겨찾기 **품의 자동입력** 클릭 → 붙여넣기 (설치는 `helper.html`의 안내 참고)
   - 마지막에 확인할 것: 예산(세부사업·원가통계비목) 선택, 요구일자, 첨부파일(견적서) 올리기는 사용자가 직접 한다.

## 함께 있는 파일

- `scripts/pumui.py` — 입력 JSON → 제목·개요·품목·자동입력 데이터. 외부 패키지 없음.
- `helper.html` — 브라우저에서 여는 품의 도우미. 같은 계산을 화면에서 하고, 칸별 복사와 자동입력 북마크를 준다.
- `bookmarklet.txt` — 즐겨찾기 URL 칸에 붙여넣는 자동입력 코드.
